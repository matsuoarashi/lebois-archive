# スプレッドシートに組み込む手順

所要 15〜20分。Square連携（手順5）は後回しでも動きます。

## 1. Apps Script を開く

既存の **製造予定表** のスプレッドシート（`製造品目` と `実績` のタブがあるもの）を開き、
**拡張機能 → Apps Script** を選びます。

## 2. コードを貼る

- 左の `コード.gs`（または `Code.gs`）の中身を全部消して、この `Code.gs` を貼り付け
- 左上の **＋ → HTML** で `Index` という名前のファイルを作り、この `Index.html` を貼り付け
  （ファイル名は拡張子なしで `Index`。大文字小文字が一致している必要があります）
- 保存

## 3. 初期セットアップを実行

スプレッドシートに戻ってリロードすると、メニューに **「le bois 日報」** が出ます。
**le bois 日報 → 初期セットアップ（シートを作る）** を実行。

初回は権限の確認が出ます。「詳細」→「安全ではないページに移動」→「許可」で進みます。
（自分で書いたスクリプトなのでこの表示になります）

作られるシート:

既存の `製造品目` シート（引取日・発注期限・商品ごとの発注数）は読むだけで、書き換えません。

| シート | 中身 | 誰が書く |
|---|---|---|
| 在庫台帳 | 品目ごとの冷凍・冷蔵 | システム（最初だけ手で） |
| 日次ログ | 1日1行。売上・在庫・差異まで全部 | システム |
| 商品対応表 | Square商品名 → 在庫の品目 | 人（商品が増えたとき） |
| 設定 | 釣銭準備金・店舗名 | 人 |

## 4. 今の在庫を入れる

**在庫台帳** に、いま実際にある数を入れます。単位は「個・切れ・食」です。

| 品目キー | 商品名 | 冷凍 | 冷蔵 |
|---|---|---|---|
| cheese | チーズケーキ | 28 | 9 |
| gateau | ガトーショコラ | 36 | 5 |
| chiffon | シフォンケーキ | 6 | 0 |
| croque | クロックムッシュ | 14 | 2 |

**設定** シートの釣銭準備金も確認してください（初期値 36,740円）。

## 5. Squareと繋ぐ（あとからでOK）

### 5-1. アクセストークンを発行

1. https://developer.squareup.com/apps を開く
2. アプリを1つ作る（名前は `le bois 日報` など）
3. 左メニューの **Credentials** → **Production** を選ぶ
4. **Access token** をコピー

> このトークンは売上も決済も読める鍵です。誰かに渡したり、
> スプレッドシートのセルに書いたりしないでください。次の手順の場所だけに保存します。

### 5-2. トークンを登録

Apps Script の画面で **⚙️ プロジェクトの設定** → **スクリプト プロパティ** →
**スクリプト プロパティを追加**

| プロパティ | 値 |
|---|---|
| `SQUARE_TOKEN` | コピーしたアクセストークン |

保存したら、スプレッドシートのメニューから
**le bois 日報 → Squareの店舗一覧を見る** を実行。
`Le Bois` が出れば繋がっています。

続けて **今日のデータを試しに取る** で、商品別の販売数が出るか確認してください。

> **Apps Script のエディタから確かめるときは、`showLocations` / `showToday` を実行してください。**
> 結果は実行ログに出ます。メニュー用の `menuLocations` / `menuToday` はダイアログを出す関数なので、
> エディタから実行すると返事を待ち続けて終わりません。

## 6. ウェブアプリとして公開

Apps Script の画面で右上の **デプロイ → 新しいデプロイ**

- 種類：**ウェブアプリ**
- 次のユーザーとして実行：**自分**
- アクセスできるユーザー：**全員**

「Google アカウントを持つ全員」にすると、LINEの中のブラウザから開いたときに
Googleログインを求められて進めなくなります。URLを知っている人だけが開ける状態です。

**デプロイ** を押すと **ウェブアプリのURL** が出ます。これがスタッフに配るURLです。

LINEのノートに貼っておけば、毎日そこから開けます。

## 7. スタッフに渡す

> 閉店後、このURLを開いて画面のとおりに進めてください。
> 在庫を数えて入れると、最後にLINEに貼る文章ができます。

## 直したくなったとき

- **商品が増えた** → 商品対応表に1行足す（Square商品名／品目キー／倍率）
- **釣銭の額が変わった** → 設定シートの数字を直す
- **在庫がずれた** → 在庫台帳を直接直す
- **画面を直したい** → このリポジトリの `src/ui.js` を直して `python3 build.py`、
  できた `gas/Index.html` を貼り替える

## うまく動かないとき

| 症状 | 見るところ |
|---|---|
| メニューが出ない | スプレッドシートをリロード。それでも出なければ Code.gs の保存忘れ |
| 実行が終わらない（回り続ける） | エディタから `menuLocations`／`menuToday`／`setup` を実行している。`showLocations`／`showToday` を使う |
| `sq0idp-` から始まる値を入れた | それはアプリケーションIDです。必要なのは `EAAA…` で始まる Access token |
| 「SQUARE_TOKEN が未設定です」 | 手順5-2 |
| 「店舗が見つかりません」 | 設定シートの店舗名と、Squareの店舗名の表記ゆれ |
| 売上が0のまま | 営業日か確認。Squareのレポート日は 3:00〜翌2:59 |
| 保存できない | デプロイの「実行するユーザー」が自分になっているか |
